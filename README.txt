현재 브라우저 자동화 방식 수정본입니다.

1. 기존 .env를 이 폴더에 복사
2. start.bat 실행
3. 처음 한 번 Playwright Chromium 설치가 필요할 수 있습니다:
   npx playwright install chromium
4. 브라우저가 실제로 열립니다.
5. 검색어 + 주제를 넣고 생성합니다.

동작:
- 나무위키 대문 접속
- 검색창 입력
- 검색
- 검색 결과에서 주제 단어가 포함된 링크만 선택
- 해당 문서 클릭
- 본문 수집
- 같은 자료를 AI에 전달하여 블로그/쇼츠 생성

주제 링크를 찾지 못하면 임의의 첫 결과를 클릭하지 않고 오류를 표시합니다.
